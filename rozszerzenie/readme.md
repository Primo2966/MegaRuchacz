# MegaRuchacz

Nadzor nad rownolegla praca w wielu oknach VS Code.

- panel z lista okien zadaniowych i liczba pracujacych workerow,
- przycisk zakladajacy izolowana kopie projektu (git worktree) w nowym oknie,
- scalanie galezi i domykanie okna jednym kliknieciem,
- podglad rejestru workerow na zywo.

Sciezke do repozytorium ustawia sie w: Ustawienia -> `megaruchacz.repo`.
